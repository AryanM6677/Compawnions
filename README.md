# Compawnions

Compawnions is an interactive pet-discovery experience that helps people explore breeds and find a companion suited to their lifestyle. It combines a guided matching quiz, scored recommendations, and detailed breed profiles in a responsive interface.

## Features

- Lifestyle-based pet matching quiz
- Ranked and explainable breed recommendations
- Searchable dog and cat breed encyclopedia
- Detailed care, temperament, and commitment information
- Responsive, animated interface for desktop and mobile
- Locally packaged breed imagery

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Zustand
- Chart.js

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

## Main routes

- `/` — landing page and discovery experience
- `/quiz` — lifestyle matching questionnaire
- `/results` — ranked recommendations
- `/wiki` — breed directory
- `/wiki/[id]` — individual breed profiles
